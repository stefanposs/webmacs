## What's New

### System Update API & One-Click Updates
- New `GET /api/v1/system/versions` endpoint for installed version info
- New `POST /api/v1/system/trigger` endpoint for one-click Docker pull + restart
- Frontend OTA view shows **One-Click Update** button when newer GitHub release available
- Docker image regex validator prevents shell injection in image references
- asyncio.Lock prevents concurrent update triggers (returns 409)

### Responsive Frontend
- Sidebar collapses on mobile (<900px) with hamburger toggle button
- New Pinia UI store for sidebar state management

### Code Quality & Security
- LoginRequest uses str with email pattern instead of EmailStr (supports .local TLDs)
- Updater aborts on failed DB backup by default (override: `WEBMACS_UPDATER_ALLOW_NO_BACKUP`)
- Safer env var parsing for ALLOW_NO_BACKUP (accepts 1/true/yes)
- Fixed `_extract_tag_from_image` for registry:port URLs
- Entrypoint uses explicit /app/src path

### Infrastructure
- Install scripts support Docker Hub pull mode
- Extended health check retries and systemd timeouts
- New `entrypoint-backend.sh` with fresh-DB detection + alembic stamp
- Updated mkdocs documentation (quick-start, troubleshooting, env-vars)
